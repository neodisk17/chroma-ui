Features

Everything you need to
manage vectors

A complete toolkit for developers building RAG applications, semantic search, and AI-powered features.

Visual Query Builder

Build sophisticated similarity searches without writing code. Filter by metadata, adjust thresholds, and see results in real-time.

  • Semantic search with natural language
  • Metadata filtering ($eq, $gt, $in)
  • Live JSON query preview
query.json 
{
  "query_texts": ["AI research papers"],
  "n_results": 10,
  "where": {
    "category": {"$eq": "research"},
    "year": {"$gte": 2023}
  }
}

Embeddings Visualization

See your high-dimensional vectors in 2D. Understand clustering, find outliers, and validate your embeddings.

Secure Connections

Credentials stored in OS keychain. Connect to local or remote ChromaDB instances.

10,000+ Documents

Virtual scrolling handles massive collections. Sort, filter, and search instantly.

Document Comparison

Compare embeddings side-by-side with similarity scores, distance metrics, and neighborhood analysis.

Bulk Import/Export

JSON and CSV support for easy data migration. Batch operations included.

Keyboard Shortcuts

Navigate fast with power-user shortcuts. Vim-style bindings available.

Dark & Light Themes

Easy on the eyes during those late-night debugging sessions.
